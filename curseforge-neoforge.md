# Essentials GG (NeoForge)

The server essentials, without the bloat: homes, warps, spawn, TPA, back,
random teleport, kits, economy, nicknames, moderation, AFK, sidebar, tab
list and Discord webhooks. Chat and every message take hex colors and
gradients.

- Every module and command can be switched off; vanilla commands are never taken over
- Chest menus for homes, warps, kits and RTP; vanilla clients can join
- Six languages, chosen per player; LuckPerms supported
- `/ess migrate essentialsx` brings over homes, money, nicknames and warps

Requires **Mycel**. Needs NeoForge, Minecraft 26.3, 26.2 or 26.1 (26.1-26.1.2), Java 25.
