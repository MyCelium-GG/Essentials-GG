# Essentials GG

The server essentials, without the bloat: homes, warps, spawn, TPA, back, random teleport, kits, economy, nicknames, moderation, AFK, sidebar, tab list and Discord webhooks. Chat and every message take hex colors and gradients.

- Moving from EssentialsX? `/ess migrate essentialsx` brings over homes, money, nicknames and warps
- Every module and command can be switched off, and vanilla commands are never taken over
- `/menu` opens one hub, with chest menus for homes, warps, kits and RTP
- Vanilla clients can join: players install nothing
- Six languages, chosen per player
- LuckPerms supported

## Install

Server side: install it on the server.

Requires [Mycel](https://www.curseforge.com/minecraft/mc-mods/mycel): install it alongside this mod. Minecraft 26.1, 26.2 and 26.3 on Fabric, Forge and NeoForge, Java 25. On Fabric you also need Fabric API.

Every setting and command is on the [wiki](https://wiki.mycelium-gg.org/essentialsgg/).
